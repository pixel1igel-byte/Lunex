# История требований Lunex (сводка)

Это сводка требований, сформированных в предыдущих обсуждениях; она не означает, что каждая функция уже реализована.

1. Создать мессенджер Lunex с Android и веб-клиентом.
2. Стиль: чёрный/тёмный фон, неоновая фиолетово-синяя луна и звезда; использовать оригинальную предоставленную картинку.
3. Функции уровня Telegram + Discord: личные и групповые чаты, сообщества/серверы, текстовые и голосовые каналы, роли, права, звонки, файлы и медиа.
4. Настраиваемость: отдельный фон каждого чата, цвета, прозрачность, blur, шрифты, размеры, формы пузырей, анимации, эффекты; обмен темами через импорт/экспорт.
5. Приватность: E2EE, минимум метаданных, независимая доставка, изучение децентрализации и onion/mixnet-маршрутизации. Не обещать абсолютную анонимность.
6. Серверная безопасность: allowlist Origin, ограничения тела запроса, лимиты сообщений, проверка канала и заголовков безопасности.
7. Android: проект Kotlin/Jetpack Compose, иконка во всех размерах, GitHub Actions для сборки APK.
8. Пользователь предпочитает получить полный комплект файлов и архив, а не только макеты, планы или разрозненные фрагменты.
9. Сохранять архивы прошлых итераций для резервной копии и сравнения.
10. Перед заявлениями о готовности подтверждать тесты и фактическую сборку; явно отмечать недостающие функции и ограничения.
